# Talenry onboarding, redesigned

A self-initiated redesign of Talenry's onboarding: people see their job matches first and are asked for details later. Not commissioned by or affiliated with Talenry.

- [Case study](https://zehandesigns-lang.github.io/talenry-redesign/case-study.html)
- [Prototype](https://zehandesigns-lang.github.io/talenry-redesign/)

Designed in Figma and brought to life through Claude. Built with React, TypeScript, Tailwind CSS and Vite.

## Run it locally

```bash
npm install
npm run dev
```

The prototype opens at http://localhost:5180 and the case study at http://localhost:5180/case-study.html.

Every push to `main` rebuilds both pages and publishes them to GitHub Pages.
